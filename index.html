How It Works

The Technology Stack

🧠

LangGraph Orchestration

Multi-agent graph with supervisor routing, parallel execution fan-out, and state management.

⚡

Parallel Fan-Out

Three specialist agents (Concept, Coder, Math) run simultaneously, reducing generation time by 3×.

🔄

Human-in-the-Loop

HITL checkpoint pauses the graph for professor review. Feedback triggers iterative re-runs.

📝

Editor Compiler

Single compilation pass aggregates all agent outputs into a clean, formatted exam paper JSON.

🔀

Deterministic Router

The Manager Agent uses programmatic routing (no LLM) to save API quota and ensure reliability.

🌐

Gemini + Web Search

Google Gemini for compilation. Tavily Search for real-time subject knowledge retrieval.
